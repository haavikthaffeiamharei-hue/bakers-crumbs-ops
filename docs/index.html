Executive summary

Baker's Crumbs is a chat assistant for an invented neighbourhood bakery. Customers ask everyday questions (opening hours, prices, pre-orders, delivery, ingredients) and get an answer in about a second, any time, instead of waiting for staff to reply. It is built on LibreChat, an open-source ChatGPT-style app, connected to Google's Gemini model, and it runs on Amazon Web Services (AWS).

This project is about running that system well. At the start nothing was watching it: when the AI model stopped answering for the first time, I only noticed because I happened to be testing. There were no backups, no alarms and one all-powerful login. I added round-the-clock monitoring with email alarms, hourly backups that I proved by deleting the database and restoring it, scheduled health checks, and a locked-down account. When the assistant failed a second time, the alarms emailed me within about three minutes and it was fixed seven minutes later.
