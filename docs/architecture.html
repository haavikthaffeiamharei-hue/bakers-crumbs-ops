AWS infrastructure design

Everything runs in one AWS account, in one region (us-east-1), on one server. The only thing outside AWS is the Gemini model.

How a question travels

  1. The customer types a question at https://23-20-79-221.sslip.io. The browser connects over HTTPS (port 443) to the server's Elastic IP.
  2. Caddy terminates HTTPS with a free Let's Encrypt certificate, adds security headers, and passes the request to the LibreChat container.
  3. LibreChat adds the Baker's Crumbs instructions (built from the five bakery documents in S3 when the app starts) and sends the question to Gemini with the API key that the start script read from Parameter Store.
  4. Gemini's answer streams back through Caddy to the browser. The chat is saved in MongoDB.
  5. Every minute the request logger writes the question, answer time, success and release to a log that the CloudWatch agent ships to CloudWatch, where metric filters feed the dashboard and alarms; alarms email me through SNS.
